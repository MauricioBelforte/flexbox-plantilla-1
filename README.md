# Plantilla 1 - Flexbox 1

Bienvenido a la **Plantilla 1 - Flexbox 1** de mi colección de diseños web. Este proyecto es una landing page  desarrollada como parte de mi portafolio para demostrar habilidades en maquetación moderna y diseño responsivo, utilizando **Flexbox** como motor principal de diseño.

Esta plantilla sirve como un ejemplo base de lo que puedo ofrecer a mis clientes: sitios web limpios, rápidos y adaptables a cualquier dispositivo.

## 📋 Descripción del Proyecto

Este proyecto recrea una página de aterrizaje (landing page) para un servicio ficticio de construcción de comunidades llamado "Huddle". El enfoque principal es el uso de **Flexbox** para gestionar la distribución de los elementos, asegurando que el diseño se vea perfecto tanto en dispositivos móviles como en escritorio.

### Características Principales

*   **Diseño Responsivo (Mobile First):** La estructura se adapta fluidamente desde pantallas de teléfonos hasta monitores de escritorio.
*   **Maquetación con Flexbox:** Uso eficiente de CSS Flexbox para alineación y distribución de contenido.
*   **Estilos Modernos:** Uso de variables CSS para una gestión de colores consistente.
*   **Tipografía:** Integración de Google Fonts ('Open Sans' y 'Poppins') para una legibilidad óptima.
*   **Activos Optimizados:** Uso de imágenes SVG para logotipos e iconos, garantizando nitidez en cualquier resolución.

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica.
*   **CSS3:** Estilos, variables y media queries.
